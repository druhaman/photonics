# Синтез фазового ДОЭ нейросетью

Сеть получает комплект из 4 изображений 128×128 и строит один фазовый ДОЭ 128×128.
При восстановлении дифракцией Френеля (одно БПФ, λ = 532 нм, пиксел 10 мкм) ДОЭ даёт
изображения на расстояниях 24.1, 25.3, 26.5 и 27.7 мм. Файлы комплекта сортируются по имени:
первый соответствует 24.1 мм, четвёртый — 27.7 мм.

## Запуск

```bash
docker build -t doe-net .
docker run --rm -v "$PWD/testsets:/data/input" -v "$PWD/out:/data/output" doe-net
```

На машине с NVIDIA GPU добавьте `--gpus all`, сеть сама выберет CUDA.

Во входной папке могут лежать подпапки-комплекты по 4 PNG или сразу 4 PNG одного комплекта.
На выходе для каждого комплекта создаётся `out/<комплект>/doe.png` (8 бит, grayscale, 0 = −π, 255 = +π),
а в `out/times.csv` записывается время синтеза.

Параметры указываются после имени образа:

```bash
docker run --rm -v ... doe-net /data/input /data/output --recon      # сохранить восстановленные изображения
docker run --rm -v ... doe-net /data/input /data/output --steps 256  # точнее, но медленнее
```

Сравнение с алгоритмом Герчберга–Сэкстона:

```bash
docker run --rm -v "$PWD/testsets:/data/input" -v "$PWD/results:/app/results" \
    --entrypoint python doe-net evaluate.py /data/input
```

Без Docker (Python 3.12): `pip install -r requirements.txt && python synth.py testsets out`.

## Метод

Модель `DOENet` (`doe/net.py`):

1. U-Net по четырём изображениям предсказывает фазу и поправку амплитуды поля в каждой плоскости.
   Поля обратно распространяются на ДОЭ и складываются, как в 3D-CGH-Net (Rymov et al., Opt. Lasers Eng. 2025).
2. Вторая U-Net уточняет фазу в плоскости ДОЭ.
3. 16 итераций многоплоскостного Герчберга–Сэкстона с обученными весами плоскостей.
4. 64 шага Adam по фазе. Шаг минимизирует ошибку восстановления 2.5·(1 − КК) + (1 − ИСС), шаг уменьшается по косинусу.
   Параметр `--steps` задаёт баланс между скоростью и качеством.

Сеть обучалась без готовых голограмм: выданный ДОЭ восстанавливается Френелем и сравнивается со входными изображениями.
Для обучения использовались MNIST, Fashion-MNIST, COCO, BSDS500 (train/val), сгенерированные буквы и фигуры.

## Результаты

Комплекты лежат в `testsets/`. Замеры сделаны в Docker на CPU.
ДОЭ сохраняется в 8-битный PNG и восстанавливается из файла. Метрики сравнивают амплитуду |K|
с исходным изображением, оба нормированы на максимум. КК и ИСС считаются по формулам задачи
и усредняются по 4 изображениям комплекта. GS — 200 итераций многоплоскостного Герчберга–Сэкстона.

| комплект | время, с: сеть / GS | КК: сеть / GS | ИСС: сеть / GS |
|---|---|---|---|
| bsds (фото) | 0.39 / 0.45 | **0.483** / 0.397 | **0.434** / 0.366 |
| natural (фото) | 0.41 / 0.48 | **0.532** / 0.515 | **0.449** / 0.417 |
| mnist | 0.40 / 0.49 | 0.670 / 0.702 | **0.550** / 0.474 |
| digits | 0.40 / 0.48 | 0.730 / 0.739 | **0.581** / 0.550 |
| letters | 0.40 / 0.47 | 0.759 / 0.779 | **0.615** / 0.555 |
| shapes | 0.38 / 0.47 | 0.661 / 0.689 | **0.472** / 0.426 |
| corners_digits | 0.41 / 0.48 | **0.500** / 0.485 | **0.265** / 0.262 |
| corners_letters | 0.41 / 0.47 | **0.498** / 0.483 | 0.262 / 0.263 |
| corners_symbols | 0.40 / 0.48 | **0.489** / 0.473 | **0.276** / 0.264 |
| corners_all | 0.40 / 0.48 | 0.738 / 0.746 | **0.568** / 0.526 |
| среднее | **0.40** / 0.47 | **0.606** / 0.601 | **0.447** / 0.410 |

Сеть быстрее GS на всех комплектах. По ИСС она лучше на 9 из 10, на corners_letters результат равный.
По КК сеть в среднем лучше и особенно заметно выигрывает на фотографиях.
В комплектах `corners_*` символы расположены в углах кадра.

Если нужно больше качества, увеличьте `--steps`:
* 256 шагов: КК 0.624, ИСС 0.471, около 1.3 с на CPU;
* 1024 шага: КК 0.639, ИСС 0.485, около 4.5 с на CPU.

На GPU это быстрее.

Если проверка использует оконный SSIM (окно 11×11), добавьте его в ошибку: `--window 1.5 --pearson 10 --steps 48`.
Получится КК 0.620, ИСС 0.435, оконный SSIM 0.140 (у GS: 0.601 / 0.410 / 0.132). На CPU это в 1.5–2 раза медленнее.

Полный отчёт и восстановленные изображения лежат в `results/`.

## Файлы

```
doe/optics.py     дифракция Френеля, чтение и запись PNG
doe/net.py        сеть
doe/metrics.py    КК, ИСС, функция ошибки
doe/gs.py         Герчберг–Сэкстон
doe/data.py       обучающая выборка
synth.py          синтез ДОЭ, точка входа контейнера
evaluate.py       метрики и сравнение с GS
train.py          обучение
make_testsets.py  генерация тестовых комплектов
tests/            проверка Френеля и метрик: python -m tests.test_optics
weights/          веса сети
```

## Обучение

Веса получены поэтапным обучением на Apple M1 Pro.
`train.py` дообучает сеть в итоговой конфигурации; для запуска с нуля уберите `--init`.

```bash
pip install -r requirements-train.txt
python train.py --iters 6000 --init weights/doe_net.pt --out weights/new.pt
```

Датасеты кладутся в `data/`. Если какого-то нет, он пропускается.

| датасет | ссылка | куда положить |
|---|---|---|
| MNIST | https://storage.googleapis.com/cvdf-datasets/mnist/train-images-idx3-ubyte.gz | `data/mnist/` |
| Fashion-MNIST | https://huggingface.co/datasets/zalando-datasets/fashion_mnist/resolve/main/fashion_mnist/train-00000-of-00001.parquet | `data/fashion_train.parquet` |
| COCO val2017 | http://images.cocodataset.org/zips/val2017.zip | `data/val2017/` |
| BSDS500 | https://codeload.github.com/BIDS/BSDS500/zip/refs/heads/master | `data/BSDS500-master/` |
